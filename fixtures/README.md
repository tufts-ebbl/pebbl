# Test fixtures

Small synthetic files the tests read. None holds participant data.

## cor_planted_75-140s.npz

A planted corrugator EMG (COR) recording, used by `test_cor_display.py` to check how PEBBL shows COR.

- **What it is:** 65 s (75-140 s) of a 300-s synthetic recording, 1000 Hz, in mV, stored as float32.
  It is mostly quiet live muscle, with three planted events: an ordinary 0.3-mV burst (79.75-80.25 s), a held
  4-s frown (100-104 s) and a cluster of electrode pops (130-130.9 s). The event names and times (in the
  source recording's seconds) are stored in the file with the signal.
- **Where it comes from:** physiopipe, the pipeline that writes the corrugator column RAs review. It planted the
  signals and filtered them once through its corrugator chain (physiopipe commit 1d6dbd8; script
  `cor_render_data.py`, kept with its companion in physiopipe's `audit/cor_rules_20261101/`). physiopipe has no
  public repository, so it is cited by name and commit only. The source file, `cor_render_quiet300.csv`, has
  SHA-256 `6d5ccc8d505b2aaf90a1b515eb40189ce02530a5ccf0c6b9cdca7be6e6534766`, also stored in the fixture.
- **Approved** for this public repository by HLU on 2026-11-01.
- **To rebuild it** (e.g. after physiopipe's corrugator filters change), get the new planted CSV from physiopipe,
  update `SOURCE_SHA256` in `make_cor_planted.py`, and run:

      annotate_env/Scripts/python.exe fixtures/make_cor_planted.py <cor_render_quiet300.csv>

## urglab_reference_sidecar.json

The sidecar of physiopipe's writer-made synthetic recording, sub-synth01. `test_urglab_practice.py` checks
urglab's practice files against it, and `practice_urglab.py` copies each column's Description from it word for
word.

- **What it is:** the JSON sidecar only, unchanged (SHA-256 `ced919006219e3bc263b868e5825e468434c97a5c8c463b85ff803bc63d203c6`).
  It holds physiopipe's final sidecar keys, the 12 columns and their units, every channel's reason list and Rule,
  and the study's RA texts. Its 19.1-MB data file stays local-only.
- **Where it comes from:** physiopipe's writer (physiopipe commit d9c276d; urglab physio cc6a468; profile SHA-256
  `21078f4f17b8...`). Every signal behind it was generated by a script; no participant or practice physiology is
  involved. Its Provenance has `Dataset` "synthetic", `Subject` "synth01", a laptop CPU model, the write time,
  software versions and commit IDs; physiopipe found nothing sensitive (2026-11-08).
- **Approved** for this public repository by HLU on 2026-11-08 (urglab practice addendum A6).
- **To refresh it** when physiopipe regenerates the file before the freeze: copy the new sidecar here, then
  update `practice_urglab.COLUMN_TEXTS` and `MACHINE_RULES` if the texts changed. A new Description means a
  new urglab practice key version.

## rsp_raw_planted_130-180s.npz

A synthetic breathing recording, used by `test_rsp_raw_row.py` to check the `rsp_raw` row.

- **What it is:** 50 s (130-180 s) of a 305-s synthetic recording, 1000 Hz: the columns `rsp_raw` (the belt as
  recorded, V), `rsp` (filtered, V) and `event`, plus RSP's machine stretches in the cut, by reason (counted from
  the cut's start). Two planted events: the belt held at the -10 V limit, then a jump past zero (140.9-143.0 s;
  machine: `rail` and `swing`), and a single 3-V belt step with a slow drift back and breathing on it (175.0 s;
  machine: `swing`). The event names and times (in the source file's seconds) are stored in the file.
- **Where it comes from:** physiopipe wrote the whole recording with the same writer that writes study files
  (physiopipe commit 5e05331; generator `make_pebbl_rsp_fixture.py`, kept in physiopipe's
  `audit/outside_review_20261107/lead/pebbl_fixture_rsp_raw_20261108/`). Every signal is generated by a script; no
  participant or practice physiology is involved. physiopipe has no public repository, so it is cited by name and
  commit only. The source `.tsv.gz` has SHA-256 `914a1151532cbf493dde1f2272982b392589341b2567b2aefe9cb425b50f9605`,
  also stored in the fixture.
- **Approved** for this public repository by HLU on 2026-11-08.
- **To rebuild it** (e.g. after physiopipe's writer changes), get the new file pair from physiopipe, update the two
  SHA-256s in `make_rsp_raw_planted.py`, and run:

      annotate_env/Scripts/python.exe fixtures/make_rsp_raw_planted.py <..._physio.tsv.gz> <..._physio.json>
